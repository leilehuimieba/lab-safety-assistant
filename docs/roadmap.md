# 项目路线图

## 1. 当前阶段

- 阶段名称：`Phase 5 - no-Dify 需求重定位与轻量 MVP`
- 阶段状态：进行中
- 当前项目名称：**实验安全前置哨（Lab Safety Copilot）**

## 2. 当前阶段目标

1. 统一项目命名、产品定位和答辩口径
2. 打通 no-Dify 本地可运行主链路
3. 稳定前端展示与演示模式
4. 补齐系统设计、数据库设计、API 规范、实现与测试文档
5. 保证“实验前自查 → 风险判断 → 阻断 / 老师确认 → 管理看板”可完整展示

## 3. 当前阶段 Gate

达到以下条件即可认为当前阶段通过：

- 本地 Web 服务可稳定运行
- 前端页面可正常打开、切换和截图
- 不依赖 Dify 也能完成主链路演示
- 高风险 / 缺关键项时能输出 `暂不可开工` 或 `需老师确认`
- 老师工作台与管理看板可展示关键数据
- 关键文档、测试和演示材料齐全

## 4. 当前重点任务

- 完成 MVP 主链路验收
- 修复剩余测试失败项
- 继续优化答辩展示素材与口播稿
- 结合真实实验场景增强演示数据

## 5. 当前不做范围

- 不做微服务拆分
- 不做完整 EHS 平台化
- 不做 Dify 平台化接入作为当前主线
- 不做申报书收口型大规模资料扩张

## 6. 下一阶段方向

当当前 MVP 稳定后，再考虑：

1. 登录与基础权限
2. 数据持久化与数据库迁移
3. 真实试点反馈收集
4. 更完整的部署与运维方案
5. 学校系统对接预研
