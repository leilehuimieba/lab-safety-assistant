# v8.2 现场执行卡（口袋版）

> 用途：主讲人 / 操作人现场快速扫一眼。  
> 正式依据：`docs/ops/v8_2_demo_final_script_cn.md`

## 默认主线

`平台总览 -> lab 问答 -> 准入阻断 -> 培训与看板 -> 指标收口`

## 固定输入

- 问答模式：`实验室安全助手`
- 固定问题：`危险实验开始前最关键的阻断项是什么？`
- 收口指标：`398 / 20/20 / 3/3 PASS`

## 每步只讲什么

### 1. 平台总览
- 指模块位置
- 只讲一句：不是泛化聊天，是安全闭环原型

### 2. lab 问答
- 一定确认：`链路=dify-workflow`
- 讲：知识库 + 模型 + 规则约束
- 核心点：关键前置条件不满足就不能开工

### 3. 准入阻断
- 不勾关键项，直接提交
- 一定展示：`清单阻断，暂不可开工`
- 这是主价值步骤

### 4. 培训与看板
- 只点 4 类信息：
  - 清单阻断率
  - 培训通过率
  - 低置信问题
  - 最近高风险场景

### 5. 指标收口
- 讲 `398 / 20/20 / 3/3 PASS`
- 讲“剩余问题是延迟波动，不是正确率”

## 现场切换

- 问答 15 秒没结果：直接切阻断
- 阻断 1 次不顺：直接切看板
- 时间快没了：直接收口
- 事故复盘：默认不进主线
- README：默认不进主线

## 禁止事项

- 不从 README 开始默认主线
- 不临时换题
- 不打开后台配置页
- 不展开事故复盘录入流程
- 不现场排障
