# 实验室安全小助手首轮试点执行清单（化学实验室）

> 文档版本：v1.0  
> 形成日期：2026-04-21  
> 用途：作为首轮化学实验室试点的现场执行清单，尽量做到“拿着就能执行”。  

---

## 一、试点目标

本轮重点验证：

1. 用户是否能理解实验室安全正式问答链路；
2. 用户是否认可“关键项未满足则不可开工”的阻断逻辑；
3. 用户是否觉得该系统在化学实验室场景下有实际辅助价值；
4. 是否能顺利拿到签到、问卷和试点记录。

---

## 二、建议参与对象

建议控制在小范围：

- 学生：5~15 人
- 助教/实验人员：1~3 人
- 指导教师/管理员：1~2 人

---

## 三、试点前准备清单

试点前请逐项确认：

- [ ] 已联系好指导教师 / 实验室联络人
- [ ] 已确认试点时间和地点
- [ ] 已确认网络和演示设备可用
- [ ] 已准备好签到表
- [ ] 已准备好满意度问卷（线上或纸质）
- [ ] 已准备好试点记录表
- [ ] `web_demo` 可打开
- [ ] 平台总览 / 智能问答 / 准入阻断 / 培训与看板 页面可见
- [ ] 知道固定问题和固定场景

---

## 四、本轮固定问题与固定场景

### 固定问题

优先使用：

`危险实验开始前最关键的阻断项是什么？`

### 固定场景

统一使用：

`夜间进行高温回流和有机溶剂加热实验`

---

## 五、现场执行顺序

### Step 1：开场说明（2~3 分钟）

建议话术：

> 今天这轮试点主要验证系统在化学实验室场景中的真实辅助价值。重点不是让大家把它当聊天机器人，而是看它能不能帮助识别实验前关键前置条件，并在不满足条件时给出明确阻断。

---

### Step 2：平台总览（1 分钟）

需指出：

1. 这是实验室安全闭环原型；
2. 当前主模块包括问答、准入阻断、培训与看板；
3. 当前统一指标口径为 `398 / 20/20 / 3/3 PASS`。

---

### Step 3：实验室安全问答（3~5 分钟）

操作：

1. 进入“智能问答”
2. 选择“实验室安全助手”
3. 输入固定问题
4. 运行问答

观察重点：

- [ ] 用户是否能理解回答不是自由发挥
- [ ] 用户是否认为回答围绕高风险前置条件有价值
- [ ] 页面是否出现正式链路口径

---

### Step 4：准入阻断（3~5 分钟）

操作：

1. 进入“准入阻断”
2. 基于当前问题生成清单
3. 不勾选关键项，直接提交

观察重点：

- [ ] 页面是否出现“清单阻断，暂不可开工”
- [ ] 用户是否能理解阻断原因
- [ ] 用户是否认可这种设计比“只给建议”更有用

---

### Step 5：培训与看板（2~3 分钟）

只需指出：

1. 清单阻断率
2. 培训通过率
3. 低置信问题
4. 最近高风险场景

观察重点：

- [ ] 用户是否理解这是面向老师/管理员的价值
- [ ] 老师是否认可该模块的管理意义

---

### Step 6：问卷与反馈（5~10 分钟）

现场完成：

- [ ] 发放或展示问卷二维码
- [ ] 提醒每位参与者填写
- [ ] 收集至少 3 条开放反馈
- [ ] 记录老师/助教的口头意见

---

## 六、试点后立刻要做的事

试点结束后当天建议完成：

- [ ] 回收签到表
- [ ] 统计问卷回收数
- [ ] 填写试点记录表
- [ ] 整理主要问题与正向反馈
- [ ] 在试点结果汇总表中补 1 行

---

## 七、最低完成标准

本轮试点至少满足以下条件才算有效：

- [ ] 已完成签到
- [ ] 已演示问答与阻断主线
- [ ] 已回收问卷
- [ ] 已填写试点记录表
- [ ] 已形成至少 3 条有效反馈

---

## 八、现场重点提醒

1. 不要临时换题；
2. 不要在现场展开太多技术细节；
3. 不要追求演示所有模块；
4. 优先保住“问答 + 阻断”主线；
5. 重点收集用户是否认可“阻断价值”。
