# 项目路线图

## 1. 当前阶段
- 当前阶段：Phase 5 - no-Dify 需求重定位与轻量 MVP
- 阶段状态：进行中
- 当前目标：
  1. 暂停申报书与 Dify 平台导向
  2. 将产品重新定位为 `Lab Safety Copilot / 实验前安全检查助手`
  3. 明确 no-Dify 自研 MVP 的目标用户、核心痛点、竞品空缺和不做范围
  4. 建立 `实验前自查 -> 风险阻断 -> 老师审核 -> 管理看板` 最小闭环
  5. 后续用本地知识库、规则引擎和模型直连替代 Dify 作为核心链路
  6. 保留 `v8.2` 现有代码和文档作为可复用资产，不作为新主线约束
- 当前主推进 change：`docs/changes/2026-04-28-demand-realignment-no-dify/`

## 2. 阶段列表

### Phase 0 - 治理底盘收口
- 目标：统一执行入口、阶段口径、change 机制、AI 协作规则
- 输入：现有 README / eval / ops / reports / proposal 文档
- 交付物：
  - `AGENTS.md`
  - `docs/README.md`
  - `docs/roadmap.md`
  - `docs/changes/README.md`
  - `docs/changes/INDEX.md`
  - `docs/templates/*.md`
- Gate：
  - 当前主线明确
  - 当前阶段明确
  - 当前 active change 明确
  - AI 可按统一读取顺序推进
- 失败回退：
  - 回退到“仅保留现有 docs，不改变业务结构”的最小状态

### Phase 1 - 演示主链路固化
- 目标：固定 `v8.2` 演示基线与复现步骤
- 输入：`release_exports/v8.2/`、`web_demo/`、`scripts/`、`docs/eval/`、`docs/ops/`
- 交付物：
  - 演示脚本
  - 主链路 verify
  - 关键命令与截图 / 证据
  - 本地 / 服务器同步与部署边界规范
- Gate：
  - demo 主链路可复现
  - 关键问题集可稳定演示
  - 答辩讲解口径一致
  - 本地与服务器同步范围清晰
- 失败回退：
  - 回退到上一个可演示版本和脚本

### Phase 2 - 答辩材料与演示验收
- 目标：完成答辩可讲、可演、可答疑
- 输入：Phase 1 固化结果
- 交付物：
  - 答辩要点
  - 指标说明
  - 常见问题回答材料
- Gate：
  - 演示链路、文档、话术一致
  - 关键指标和证据可快速出示
- 失败回退：
  - 回退为“精简演示版本”，缩小讲解范围

### Phase 3 - 可选平台化增强
- 目标：推进稳定化、健康检查、prod 收敛、回滚演练
- 输入：展示阶段稳定成果
- 交付物：
  - prod gate 修复
  - 服务器实链路验收
  - 回滚演练记录
- Gate：
  - readiness 满足要求
  - 回滚路径已验证
- 失败回退：
  - 保留展示主线，不阻塞课程交付

### Phase 4 - 申报书承诺兑现与结题收口
- 目标：将申报书中的四大模块、三阶段目标、最终指标和预期成果转为可验证交付物
- 输入：`standard_from_doc.docx`、现有 `v8.2` 演示基线、知识库、评测集、发布脚本、试点反馈材料
- 交付物：
  - 申报书兑现版需求规格说明
  - 申报书目标与当前项目差距矩阵
  - `≥1000` 条核心知识库阶段包
  - `≥3000` 条最终结构化知识库或结题口径说明
  - 有效回答率、专业准确率、安全拒答率、意图识别率、响应时延评测报告
  - 真实学生 / 老师试点反馈
  - 结题验收包、技术路线、用户手册、部署与运维说明
- Gate：
  - 每项申报书承诺均有 `已完成 / 部分完成 / 待完成 / 后置` 状态
  - 不用绝对化表述替代真实评测证据
  - 知识库规模、质量和来源可追溯
  - 真实试点反馈和评测报告可归档出示
- 失败回退：
  - 保留 `v8.2` 作为演示原型，结题材料中明确说明未达最终指标的原因、风险和后续计划

### Phase 5 - no-Dify 需求重定位与轻量 MVP
- 目标：从 Dify/RAG 平台导向切换为 no-Dify 自研轻量版实验前安全检查助手
- 输入：市场/竞品调研结论、现有 `web_demo`、`safety_rules.yaml`、本地知识库、风险评估和看板能力
- 交付物：
  - no-Dify PRD
  - MVP 任务拆分
  - 实验前自查表单
  - 风险等级与阻断规则
  - 开工检查清单
  - 老师审核包
  - 本地知识库问答与来源引用
  - 低置信问题队列
  - 管理看板
  - pytest / 浏览器走查证据
- Gate：
  - 不依赖 Dify 也能完成主链路演示
  - 高风险/缺关键项场景能输出 `暂不可开工` 或 `需老师确认`
  - 老师可看到审核摘要
  - 低置信问题不硬答并进入队列
  - 管理看板可展示风险热点和待处理事项
- 失败回退：
  - 回退到现有 `v8.2` 演示原型，Dify 作为可选历史链路保留

## 3. 阶段切换规则
进入下一阶段前必须满足：
- 当前阶段交付物齐全
- 当前阶段 Gate 明确通过
- 相关 change 已收口或冻结
- `verify.md` 证据已补齐
