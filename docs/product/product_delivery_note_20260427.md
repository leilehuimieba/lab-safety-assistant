# 产品化交付说明（当前版本）

版本：`product-preview-20260427`

## 当前定位

实验室安全助手不是单纯聊天页面，而是一个轻量安全工作台：

1. 学生：问安全问题、判断能不能开工、完成培训；
2. 老师：看待审核开工、高风险提醒、未完成培训名单；
3. 管理员：看知识库、证据链接、测试结果、导出验收材料。

## 已产品化的能力

| 模块 | 当前能力 |
|---|---|
| 智能问答 | 结合规则、知识库和模型回答实验室安全问题 |
| 准入阻断 | 根据实验场景生成开工检查，阻断高风险场景 |
| 培训 | 抽题、评分、记录通过情况 |
| 老师工作台 | 待审核、高风险、未完成培训、处理建议 |
| 名单管理 | 下载模板、上传 CSV、查看/复制未完成名单 |
| 管理员看板 | 知识库数量、证据链接、测试结果、导出验收包 |
| 事故复盘 | 记录事故、原因、整改和闭环状态 |

## 适合当前阶段的使用方式

1. 先作为课题验收和试点工具使用；
2. 老师用 CSV 管理班级名单，不强行对接学校平台；
3. 学生在本系统完成培训和开工检查；
4. 管理员定期导出材料，用于汇报和验收。

## 还不是正式平台的部分

1. 未接学校统一身份认证；
2. 未接教务/学生平台；
3. 账号权限仍是轻量角色切换；
4. 数据存储仍以本地 CSV 为主。

这些不影响当前验收和小范围试点。

## 下一步最值得做

1. 增加登录和基础权限；
2. 把 CSV 存储换成数据库；
3. 增加真实试点反馈记录；
4. 再考虑是否对接学校学生平台。
