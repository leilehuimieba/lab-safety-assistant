# 前端演示模式说明（2026-05-11）

## 目的
为答辩 / 汇报 / 截图场景提供稳定、完整、观感更好的展示数据，不依赖后端实时返回。

## 使用方式

### 方式 1：URL 打开演示模式
访问：

`http://127.0.0.1:8088/?demo=1`

说明：
- 首次访问后会自动把演示模式写入浏览器本地存储
- 刷新页面后仍保持演示模式

### 方式 2：退出演示模式
访问：

`http://127.0.0.1:8088/?demo=0`

或点击页面右下角“退出演示模式”按钮。

## 演示模式特点
- 页面内容完整，适合截图
- 高风险、阻断、老师审核、事故记录等效果更明显
- 可以稳定复现演示逻辑
- 不影响真实接口模式，随时可切回
