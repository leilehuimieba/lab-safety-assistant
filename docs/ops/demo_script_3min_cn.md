# 实验安全前置哨（Lab Safety Copilot）3 分钟演示脚本

## 1. 开场（20 秒）

大家好，我们的项目叫**实验安全前置哨（Lab Safety Copilot）**。它不是一个普通的 AI 聊天工具，而是一个面向高校实验室场景的**实验前安全决策系统**。它解决的核心问题是：学生准备做实验前，系统能不能帮助判断**当前到底能不能开工**。

## 2. 展示主链路（100 秒）

第一步，我们从首页进入“开工检查”。

学生输入实验名称、试剂、设备和操作步骤后，系统会自动识别风险点，并生成一份开工前检查清单。

第二步，我们故意不确认某些关键项，比如 SOP、PPE 或通风条件。此时系统不会只给出一段建议文字，而是直接输出结构化结论，例如：**暂不可开工**，并明确告诉我们阻断原因是什么。

第三步，如果实验属于高风险场景，这条记录会进入**老师工作台**。老师不需要重新看一大段描述，只需要查看摘要、缺失项和建议动作，就可以快速做出确认或驳回。

第四步，在**管理看板**里，可以看到高风险场景数量、低置信问题、事故状态等统计结果。这意味着系统不仅能给出单次判断，也能支撑后续管理分析。

## 3. 技术亮点（40 秒）

这个项目的特点有三个：

1. **主线清晰**：聚焦实验前，而不是泛化聊天。
2. **闭环完整**：从学生自查、风险阻断到老师审核和管理看板形成闭环。
3. **演示稳定**：当前支持本地运行和前端 mock 演示模式，适合答辩展示与截图。

## 4. 收尾（20 秒）

一句话总结：

> 我们不是做“会回答问题的 AI”，而是做“能在实验开始前帮助判断是否可以开工的安全决策助手”。
