# v8.2 演示 verify 提交清单

> 用途：在真实彩排后快速检查“这次记录是否足够支撑最终冻结判断”。  
> 配套文档：`docs/ops/v8_2_demo_freeze_gate_cn.md`

## 必交项

- [ ] 已填写一份真实计时彩排记录
- [x] 已记录实际执行顺序
- [ ] 已记录实际总时长
- [ ] 已记录是否触发阈值 A / B / C / D / E
- [x] 已记录 README 是否保留
- [x] 已记录事故复盘是否保留
- [x] 已记录下轮唯一微调重点
- [x] 已确认收尾口径是否稳定（浏览器级初步确认）

## 可选但推荐

- [x] 有彩排截图（会话内浏览器自动化截图）
- [ ] 有彩排录像
- [ ] 有主讲人和操作人的角色分工记录

## 快速判断

### 可以进入最终冻结复核
- [ ] 是
- [x] 否

### 如果不能进入复核，缺什么
- 缺 1 次带完整主讲话术的人工计时彩排
- 缺实际总时长记录
- 缺阈值触发记录
- 缺主讲人与操作人的现场分工证据
